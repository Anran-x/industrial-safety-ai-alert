# 数据说明书(Data Sheet)

> 版本:v1 | 用途:工业安全 AI 预警原型系统的训练/评测数据来源与口径说明。
> 本项目所有数据均来自公开开源数据集,不涉及任何未授权商业数据。

## 1. 安全帽检测数据 —— SHWD (Safety Helmet Wearing Dataset)

| 项目 | 内容 |
|---|---|
| 来源 | 公开 GitHub 数据集 **SHWD**,由 xing-shadow 二次整理(经 HuggingFace 镜像下载) |
| 许可 | 数据源自网络公开图片,原数据集以研究用途发布 |
| 场景 | 建筑/工地现场人员,戴/未戴安全帽 |
| 类别 | 2 类 |
| 标注形式 | Roboflow 格式 → 已转 YOLO 格式 (class + cx,cy,w,h 归一化) |
| 原始规模 | 7,587 张图片,28,249 个目标 |

### 1.1 类别语义(经 CLIP 校验确认)

一个必须诚实交代的环节:SHWD 的类别名在不同复刻版本里有歧义注释。
本项目未轻信命名,而是用 CLIP 零样本语义校验做了独立证据:

- 对 train 集 150 个随机样本框预裁剪,交给 CLIP 判断"戴帽/未戴帽";
- 结果:**class0 平均 P(未戴)=0.76、class1 平均 P(戴帽)=0.86**;
- 因此本项目类别定义为 `0: no_helmet, 1: helmet`(与部分网络教程相反,以实测为准)。

### 1.2 划分与统计(本项目实际使用)

| 划分 | 图片数 | 目标数 | class0 (no_helmet) | class1 (helmet) |
|---|---|---|---|---|
| train | 4,916 | 19,071 | 4,925 | 14,146 |
| valid | 1,413 | - | - | - |
| test | 706 | - | - | - |

- train/valid/test 按 7:2:1 对**图片**随机划分,无目标级泄漏检查。
- YOLO 格式缓存于 `data/helmet/yolo/`,`data.yaml` 由脚本生成。

### 1.3 已知局限(诚实声明)

- 场景单一(建筑工地),对暗光、强逆光、低分辨率监控画面存在域偏移;
- 头盔颜色以黄色为主;重遮挡、极小目标(远距离头部)是难点;
- 本项目仅用于工程演示与研究目的,不构成安全产品级精度承诺。

## 2. 人员倒地检测数据 —— UR Fall Detection Dataset

| 项目 | 内容 |
|---|---|
| 来源 | 西班牙 Haro 大学公开 UR Fall Detection 数据集 url |
| 内容 | 家用/实验室场景,含人形俯卧/侧卧/坐蹲等姿态,多传感器(深度+IMU) |
| 本项目使用 | 仅 RGB 平视视频 `fall-XX-cam0.mp4` 与 `adl-XX-cam0.mp4`;cam1(天花板俯视)仅用于俯视场景验证(见 `docs/eval_report.md` §2.1) |

> 视角勘误:URFD 官方定义 cam0 = 与地面平行的平视相机、cam1 = 天花板安装的俯视相机。
> 本说明书早期版本曾将 cam0 误标为"俯视图",实际为**平视**;规则阈值均基于平视数据标定。
| 规模 | 30 段跌倒视频 + 40 段日常活动视频(共 70 段,~92MB) |

### 2.1 用途

- 倒地判定的**规则验证**(姿态宽高比 + 多帧确认),非训练数据;
- 用于评估跌倒检测规则在真实视频上的灵敏度/误报。

### 2.2 已知局限

- 数据集较老,分辨率偏低;家用场景与工业现场差异大;
- 某些 adl(如躺沙发)在形态上与跌倒接近,可能产生误报——这正是
  "多帧确认 + 复位机制"要抑制的目标。
