# 工业安全 AI 智能预警系统 — 需求文档

版本:0.1 | 日期:2026-08 | 状态:立项

## 1. 项目背景

固废处理、能源、制造等行业厂区长期存在以下安全管理痛点(基于作者 3 年能源/制造行业安全信息化落地经验,以固废事业群安全预警场景为原型):

- **安全帽佩戴**:厂区作业人员未按规定佩戴安全帽,人工巡检无法 24 小时全覆盖,依靠保安盯监控不现实;
- **人员倒地**:高温、粉尘、有毒气体环境下突发晕倒/滑倒,发现不及时会错过黄金救援时间;
- **危险区域闯入**:卸料口、抓斗作业区、配电房等高风险区域,人员误入极易造成机械伤害。

传统方案(纯人工监控)依赖人力且漏报率高;本项目的目标是构建一套**基于计算机视觉的实时预警原型系统**,验证"算法 → 告警 → 处置"闭环在厂区安全场景的可行性。

## 2. 项目目标

- 对厂区监控视频流实现三类事件的实时识别与告警:**未佩戴安全帽、人员倒地、危险区域闯入**;
- 告警输出带证据链(截图、时间、位置、事件描述),支持事后追溯与责任认定;
- 以"演示可用、指标可查、部署可移植"为验收底线,而非生产级工程。

## 3. 功能需求

| 编号 | 功能 | 说明 | 验收要点 |
|---|---|---|---|
| F1 | 安全帽佩戴检测 | 识别画面中"未佩戴安全帽的人员" | 输出类别与置信度,标注效果可视化 |
| F2 | 人员倒地检测 | 检测倒地事件,含持续判定 | 持续 N 帧确认,减少瞬时误报 |
| F3 | 危险区域闯入 | 预定义多边形区域,人员轨迹进入即告警 | 支持区域配置、越界告警 |
| F4 | CLIP 零样本兜底 | 对低置信度检测结果做语义复核 | 对比实验:误报数下降 |
| F5 | 告警事件记录 | 告警写入 SQLite:时间/类型/区域/截图/描述 | 可查询、可导出 |
| F6 | 告警多模态报告 | 事件生成结构化文本描述(含建议动作) | 报告可读、字段完整 |
| F7 | Web 演示端 | Gradio 页面:视频流实时检测 + 告警面板 | 浏览器可运行,1 分钟内启动 |

## 4. 非功能需求

- **实时性**:1080p 视频 CPU 推理 ≥ 5 FPS(可接受级),GPU 推理 ≥ 15 FPS;
- **可解释性**:每个告警附带判定依据(检测置信度、关键点数据、区域规则),便于现场人员理解与复核;
- **可移植性**:核心推理层与 UI 解耦,可替换为 MFC 桌面端或接入海康相机 SDK;
- **硬件约束**:开发机 GTX 1050 Ti 4GB,训练用轻量模型(YOLO11n),推理可 CPU 运行。

## 5. 技术选型与理由

| 模块 | 选型 | 理由 |
|---|---|---|
| 目标检测 | Ultralytics YOLO11n | 轻量(4GB 显存可训)、易部署、社区成熟;对比 RT-DETR 推理开销更低,对比 YOLOv5 精度/速度均衡更优 |
| 多目标跟踪 | ByteTrack | 轻量、无需额外训练,关联稳定性好,便于轨迹-区域规则判定 |
| 倒地判定 | 姿态关键点 + 规则(头踝高度比、躯干倾角、持续帧数) | 数据量小的情况下规则法可解释、可调参;不选时序模型(LSTM/Transformer)原因:训练数据不足、不可解释、部署重 |
| 零样本兜底 | OpenAI CLIP(ViT-B/32) | 开放类别语义复核,弥补固定类别模型的"未知场景"盲区 |
| 告警报告 | 结构化模板 + 可选大模型增强 | 4GB 显存无法本地跑 VLM,模板保证确定性,API 作为增强项(成本可控) |
| 演示端 | Gradio | 浏览器即开即用,现场演示稳定;后续可封装 MFC 桌面版 |
| 告警存储 | SQLite | 零部署、单文件、SQL 可查 |

## 6. 数据需求

| 任务 | 数据源 | 规模 | 用途 |
|---|---|---|---|
| 安全帽检测 | SHWD 公开数据集 | ~7500 张(戴/未戴) | 训练 + 验证 |
| 倒地检测 | UR Fall / Le2i Fall 公开集 + 网络监控素材 | 视频若干段 | 规则调参与验证 |
| 闯入检测 | 与倒地共用监控素材 + 自定义 ROI | — | 规则验证 |

详细说明见《数据说明书》(docs/data_sheet.md)。

## 7. 交付物

- 可运行的预警原型系统(代码仓库,含 README 与运行说明);
- 每个检测任务的评估指标报告(精确率/召回率/F1/误报样例);
- 误报对比实验(YOLO vs YOLO+CLIP);
- 演示视频与录屏;
- 项目陈述材料(3 分钟项目陈述 + 常见追问应答)。

## 8. 风险与局限(诚实声明)

- 训练数据量有限(SHWD 以工地场景为主,与固废厂区存在域差异),模型精度存在上限;
- 倒地检测依赖公开数据,演示素材非真实产线,现场效果需要再采集数据迭代;
- 原型未经历产线长期运行,不声明"误报率"等生产指标;
- 无多相机/门禁联动,仅验证算法可行性。
